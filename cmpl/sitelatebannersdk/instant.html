Fixture: Instant Cookie Banner, hosted CMP (control)

Domain key: sitelatebannersdk

Purpose: The control for the late-banner hosted-CMP fixture. Identical site and identical snippet, injected immediately on load, so a scan of this page and a scan of index.html differ in one variable only: when the banner appears.

Delay: none. Override per load with ?delay=<ms> if you want this page to behave like the late one.

Setup: the consent snippet goes in consent-code.html, pasted verbatim. Both pages read that one file. Until it is filled in, the status line below reports the snippet as empty.

Welcome to SiteLateBannerSDK (instant)

The same compliant opt-in site, with the consent snippet injected as soon as the page loads. Every compliance check should pass here no matter how long the scanner waits.

What the scanner should find here

  • Banner present, detected through the hosted CMP's own selectors and SDK probe — not a look-alike
  • Compliance type and category set come from the property's own configuration, not from this page
  • No analytics or advertising cookies before consent
  • Accept All sets _ga, _gid (analytics) and _fbp, fr (advertising)
  • Reject All sets none of them and clears any that exist
  • Banner comes back on a revisit without consent, and stays away once consent is stored

Not covered here: tracker auto-blocking. This fixture isolates one variable — when the banner appears — and anything injected at the delay mark is far too late to block a tracker anyway, so including it would only add noise to the result.
