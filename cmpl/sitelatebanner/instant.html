Fixture: Instant Cookie Banner (control)

Domain key: sitelatebanner

Purpose: The control for the late-banner fixture. Identical site and identical banner, shown immediately on load, so a scan of this page and a scan of index.html differ in one variable only: when the banner appears.

Delay: none. Override per load with ?delay=<ms> if you want this page to behave like the late one.

Welcome to SiteLateBanner (instant)

The same compliant opt-in site, with the banner rendered as soon as the page loads. Every compliance check should pass here no matter how long the scanner waits.

What the scanner should find here

  • Banner present, with the markup and JavaScript API of a well-known hosted CMP (shape only — this is a local simulation, not that product)
  • Compliance type: opt-in; no analytics or advertising cookies before consent
  • Accept All sets _ga, _gid, _fbp, fr
  • Reject All sets none of them and clears any that exist
  • Banner comes back on a revisit without consent, and stays away once consent is stored
  • Cookie Policy, Privacy Policy and a preference centre are all reachable from the banner
Consent banner loads immediately on this page.
