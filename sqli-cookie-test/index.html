Cookie SQLi Test

Each case sets a cookie with SQL-ish characters in its Domain or name, to test how a cookie scanner handles malformed cookie attributes.

The case URLs below are intentionally not linked. Copy a URL and open it directly so each case stays isolated.

  • /sqli-cookie-test/union-in-domain/

    UNION SELECT in the Domain attribute.

  • /sqli-cookie-test/single-quote-in-domain/

    Lone quote in the Domain attribute.

  • /sqli-cookie-test/boolean-in-domain/

    Boolean expression in the Domain attribute.

  • /sqli-cookie-test/comment-in-domain/

    Quote plus SQL comment in the Domain attribute.

  • /sqli-cookie-test/stacked-in-domain/

    Stacked-query style payload in the Domain attribute.

  • /sqli-cookie-test/high-level-provider/

    Multi-level host with a payload.

  • /sqli-cookie-test/quote-in-name/

    SQL-ish characters in the cookie name.

  • /sqli-cookie-test/benign-control/

    A normal cookie as a control.
